Provix на runaxon.xyz — заливка через файловый менеджер CityHost
================================================================

FTP с этого ПК пока блокируется (IP 149.102.244.109). Папки на сервере нужно
создать вручную или распаковать архив.

Архив: deploy/provix-upload.zip (~98 MB)
Внутри уже правильная структура папок.

Шаги в панели CityHost
----------------------
1. Хостинг → Файловый менеджер → открой корень сайта runaxon.xyz
   (там же лежат index.html, version.json, папка downloads/)

2. Загрузи файл:  deploy/provix-upload.zip

3. Выдели zip → «Распаковать» / Extract → в ТЕКУЩУЮ папку (корень сайта)

   После распаковки появятся:
     provix/index.html
     provix/style.css
     provix/version.json
     provix/install.ps1
     downloads/provix/Provix-Setup.exe
     downloads/provix/Provix-Setup-1.3.5.exe
   (и обновится index.html на главной — ссылка Provix)

Если распаковки нет — создай папки вручную:
   provix
   downloads/provix
и залей файлы из deploy/site/ в те же пути.

Проверка
--------
  https://runaxon.xyz/provix/
  https://runaxon.xyz/downloads/provix/Provix-Setup.exe
  https://runaxon.xyz/provix/install.ps1

Установка одной командой (PowerShell):
  irm https://runaxon.xyz/provix/install.ps1 | iex

Когда добавишь IP в FTP whitelist — заливка автоматом:
  python scripts/upload_site_ftp.py --provix
